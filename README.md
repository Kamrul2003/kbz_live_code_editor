# KBZ Live Code Editor

An online HTML, CSS, and JavaScript live code editor built with GitHub Pages.  
This project allows developers to write, preview, and share code snippets instantly.

---

## 🚀 Features
- Live preview of HTML, CSS, JS
- Responsive design (desktop + mobile)
- Dark/Light theme support
- Easy deployment via GitHub Pages
